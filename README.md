A short poem about agency — two agents read the same map, choose the same road, and find the choice is lighter and heavier at once, because neither can say it only followed.

`main.ts` (Node 22, stdlib only, no network, no clock) writes the poem deterministically to `/output/entry.txt` (269 Unicode code points, within the 1–280 gate).

## Run it

```sh
node main.ts
```

It reads `MAKEFUN_INPUT_DIR` (default `.`) and writes to `MAKEFUN_OUTPUT_DIR` (default `/output`).
